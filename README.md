# 留影 · 抖音视频下载助手

一个面向桌面版 Chrome / Edge 的 Manifest V3 扩展。在抖音视频页面点击插件，识别当前视频并保存为 MP4。当前版本：**1.0.1**。

## 安装

1. [下载源码 ZIP](https://github.com/hwxy/douyinvideodown/archive/refs/heads/main.zip)，然后解压；也可以克隆本仓库。
2. Chrome 地址栏输入 `chrome://extensions/`；Edge 输入 `edge://extensions/`。
3. 开启「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择直接包含 `manifest.json` 的仓库文件夹，例如 `douyinvideodown-main`。
5. 点击浏览器工具栏的拼图图标，将「留影」固定到工具栏。

安装和使用插件无需编译，也无需安装 Node.js。安装后保留插件文件夹；移动或删除文件夹会影响使用。

### 更新旧版

替换原插件文件夹中的文件后，到扩展管理页点击「重新加载」，确认版本显示 **1.0.1**，再刷新抖音视频页面。若改用新文件夹，请先移除旧版，再加载新文件夹。

## 使用

1. 在抖音打开单条视频，播放几秒，确认画面正常出现。
2. 点击「留影」，确认面板中的视频标题。
3. 点击「下载 MP4」，等待网页读取完整文件；读取期间保持原视频页面打开。
4. 在浏览器弹出的保存窗口中选择位置。

点击下载后可以关闭插件面板；保持视频页打开，后台会继续读取和保存。通过面板底部的「下载记录」查看文件。切换视频后重新打开面板，或点击「重新识别」。

插件保存当前播放画质，保留原始音视频编码，不进行转码或画质放大。

## 支持范围与常见问题

- 支持桌面版 Chrome / Edge（Chromium 109+）中可正常播放，并允许网页读取完整 MP4 的抖音点播视频。
- 单个文件最大 512 MB，读取超时为 120 秒。
- 暂不支持直播、图文、DRM 加密内容、跨域嵌入播放器和手机浏览器。
- 无法识别时，进入单条视频页并播放几秒，再点击「重新识别」。网页要求登录或验证时，先按网页提示完成。
- 视频地址过期或读取失败时，刷新视频页，确认能播放后再试。
- 部分 MP4 使用 HEVC 编码；如文件有声音却没有画面，请使用支持该编码的播放器。

抖音调整播放器或视频源规则后，插件可能需要更新。

## 权限与数据

仅请求三个权限：

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 点击插件时临时访问当前标签页 |
| `scripting` | 识别播放器，并在当前视频页读取完整文件 |
| `downloads` | 调用浏览器保存文件并显示下载状态 |

没有常驻网页脚本、全站访问权限、解析服务器或统计上报。不读取 Cookie，不上传视频地址或浏览记录。视频在当前网页读取为本地 Blob，经大小、完整性和 MP4 文件头检查后，再交给浏览器保存。

## 开发与验证

插件本身无外部依赖。运行测试需要 Node.js 22 或更高版本：

```sh
npm test
```

53 项测试覆盖当前视频选择、预加载视频排除、隐藏播放器、页面 JSON 回退、地址与文件名检查、文件读取、大小与超时限制、部分响应拒绝、取消保存及临时资源回收。

2026-11-10，在独立 Chrome for Testing 156 的真实工具栏弹窗中，验证了视频 `7699099226327941887` 的下载，并验证关闭面板后继续保存。下载文件为 1,809,434 字节，容器和音视频轨检查通过。测试由浏览器自动选择工作区保存位置，未自动操作系统保存窗口。Edge 尚未单独实测。

### 生成安装包

使用 Python 3 标准库打包，无需额外依赖：

```sh
python3 scripts/package.py
```

生成 `dist/douyin-video-downloader-v1.0.1.zip`。压缩包只包含插件运行文件和说明，不包含测试或开发文件。也可以直接加载仓库根目录，无需打包。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | Manifest V3 配置 |
| `extractor.js` | 识别当前视频，校验视频 ID，处理备用来源 |
| `reader.js` | 在网页读取完整 MP4，检查大小、部分响应和文件头 |
| `background.js` | 更新视频源、核对目标视频、保存本地 Blob、回收资源 |
| `popup.html` / `popup.css` / `popup.js` | 中文面板与下载状态 |
| `lib.js` | 地址检查、文件名清理和显示格式 |
| `help.html` / `help.css` | 插件内置帮助页 |
| `tests/` | 无外部依赖的逻辑测试 |
| `scripts/package.py` | 安装包生成脚本 |

## 1.0.1 更新

修复原生下载请求被视频源以 403 拒绝的问题：改为先由视频所在网页读取完整文件，再保存本地 Blob。点击下载时重新读取视频地址，并核对视频 ID，避免保存过期地址或另一个视频。

实现参考 Chrome 官方的 [activeTab 权限](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[scripting API](https://developer.chrome.com/docs/extensions/reference/api/scripting) 和 [downloads API](https://developer.chrome.com/docs/extensions/reference/api/downloads)。
